# Carnaverone Studio A.I. — GitHub Organization Profile

This repository contains the public-facing profile configuration and visual assets for the **Carnaverone Studio A.I.** GitHub organization.

It is not a project workspace, product repository, or governance authority.

## Public profile

- [Organization profile](profile/README.md) — the bilingual presentation displayed on the organization overview.
- [Profile hero artwork](profile/assets/profile-hero.svg) — banner embedded in the profile README.
- [Brand images](profile/images/) — existing logo assets retained for profile and repository use.

## Maintenance rules

1. Preserve the existing profile content and bilingual structure when making changes.
2. Add or update assets in this repository so the organization profile does not depend on a personal account repository.
3. Keep public-facing copy accurate; do not describe proposed, private, or unverified work as released.
4. Do not store credentials, private operational details, unreleased production material, or confidential member information here.
5. Check image paths, links, mobile rendering, and the public profile after each change.
6. Keep the organization identity distinct from the personal identities and workspaces of its members.
